# Pengurusan PRS SK Jawi

Wrapper GitHub Pages untuk aplikasi **Pengurusan Pembimbing Rakan Sebaya (PRS)** SK Jawi, supaya boleh dipasang sebagai ikon di skrin utama telefon.

*Bantu Diri, Untuk Bantu Orang Lain* — We listen, we care.

## Kandungan
| Fail | Fungsi |
|---|---|
| `index.html` | Memaparkan Web App Apps Script dalam skrin penuh |
| `manifest.json` | Maklumat aplikasi untuk ikon telefon (PWA) |
| `sw.js` | Service worker supaya boleh "Install app" |
| `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png` | Ikon aplikasi |

## Tukar pautan Web App
Jika deploy baharu di Apps Script, tukar `APP_URL` dalam `index.html`.
